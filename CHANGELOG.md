# История изменений

## Unreleased

### Добавлено

- Независимые модули протокола SUMP, ECA-контроллера и прикладной логики.
- Адаптер STM32 с ограниченным ожиданием остановки DMA и обработкой ошибок.
- Нативные тесты, ASan/UBSan и тесты Cortex-M4 в QEMU.
- Модель QEMU для GPIOD, DMA2 Stream 5, TIM1/TIM8 и генератора тестовых сигналов.
- Docker-окружение и единый локальный/CI сценарий с логами и JUnit.
- Публикация проверенных файлов прошивки в GitHub Releases по тегам версий.
- Контрольные суммы и метаданные происхождения сборки.
- Автоматическая проверка границ USER CODE в файлах CubeMX.

### Исправлено

- Разбор SUMP-команд, разделённых между USB-пакетами или объединённых в пакет.
- Бесконечное ожидание готовности USB из обработчиков прерываний.
- Владение буфером при незавершённой передаче, RESET и переподключении USB.
- Переполнение счётчиков, выход DMA за границы буфера и невыравненные чтения.
- Завершение захвата без триггера и вычисление периода с PSC/ARR.
- Повреждённый маркер USER CODE END INCLUDE в исходном USB-адаптере.

### Совместимость

- Сохраняются SUMP ID `1ALS`, восемь каналов PD0…PD7 и буфер 28 КиБ.
- Неподдержанные RLE/DDR/внешний clock/фильтр отклоняются перед запуском DMA.
- Триггер по-прежнему реагирует на любой выбранный фронт EXTI; многобитное
  сравнение уровней и многоступенчатые триггеры не реализованы.
- QEMU не проверяет физический USB, электрические характеристики и реальные
  предельные частоты захвата. Требуется проверка на плате перед аппаратным релизом.
