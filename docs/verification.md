Нативные тесты покрывают framing всех длинных opcodes, разные границы пакетов,
endianness, метаданные, крайние делители и размеры, состояния ECA, snapshot
конфигурации, USB busy/retry, владение отправляемым буфером, RESET, reconnect,
порядок кольцевых данных и максимальный буфер. Интеграционные тесты в QEMU
проверяют GPIOD, захват без триггера, DMA-кольцо, нарастающий/спадающий фронт,
посттриггерный счётчик, отмену и ошибку DMA с последующим восстановлением.

Успешный запуск выдаёт:

```text
ALL CORE TESTS PASSED
ALL BOARD ADAPTER TESTS PASSED
ALL STM32 CAPTURE TESTS PASSED
```

Исходные HAL/USB ST дают предупреждения об unused parameters. Современный linker
также предупреждает о RWX-сегменте в старом CubeMX linker script и заглушках
системных вызовов newlib. Генерируемый linker script оставлен без изменений;
эти предупреждения не трактуются как доказательство ошибки тестов или аппаратной
работоспособности. Новые переносимые модули и тесты компилируются с `-Werror`.

## Контейнерный CI/CD

Docker CLI/Buildx и Docker Engine установлены в пользовательском окружении macOS
через Lima; отдельная VM `sump-docker` использует Linux arm64. Проверена настоящая
Docker-сборка, а не только синтаксис Dockerfile. При первом запуске выявлены и
исправлены недостающие `bzip2` для сборки QEMU и `libc6-dev` для нативных тестов.
До их исправления release artifact корректно не создавался.

Текущий набор проверок:

- самопроверка CI-сценария;
- границы секций CubeMX;
- нативные тесты;
- ASan/UBSan;
- ядро в QEMU;
- STM32-драйвер в расширенном QEMU;
- сборка прошивки.

Результаты: `out/ci/reports/summary.md`, `junit.xml`, `results.json` и логи этапов.
Проверенные файлы: `out/ci/dist/`; происхождение сборки — в `build-info.json`,
контрольные суммы — в `SHA256SUMS`. Локальное состояние содержит незакоммиченные
изменения, что отражено в метаданных.

Workflow CI/CD подготовлен и проверен локально. Push в GitHub, публикация Release,
изменение branch protection и запуск на GitHub runner linux/amd64 не выполнялись.
Базовый Docker digest поддерживает обе архитектуры linux/amd64 и linux/arm64.
